CORBAN ENTERPRISES SIMPLE WEBSITE

FILES:
- index.html
- style.css
- script.js

IMPORTANT:
Delete the old index.html, style.css and script.js from the GitHub repository first.
Then upload these three new files directly to the repository root.

GITHUB UPLOAD STEPS:
1. Extract this ZIP file.
2. Open the CORBAN repository.
3. Delete old index.html, style.css and script.js.
4. Click Add file > Upload files.
5. Upload the new index.html, style.css and script.js.
6. Click Commit changes.
7. Wait 1 to 3 minutes.
8. Open the website and press Ctrl + F5.
